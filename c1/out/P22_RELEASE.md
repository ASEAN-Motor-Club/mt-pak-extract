source, so an unrotated port faces backwards.

## Time Attack name fix

The earlier rename wrote the C1 name into the native rows. Root cause was in the patcher, not
the data: `append_struct_clone` shallow-copies the template row's field list and
`set_description`/`set_localization_guid` mutated that shared `TextPropertyData` in place, so
writing the clone's name also renamed the row it was cloned from — `DriveMaps[0]` (`Island`) and
`TimeAttackMaps[0]` (`Town Circuit 1`). Both ops now replace the property inside its container.
Measured: `Island` 1→0→1, `Town Circuit 1` 2→1→2, `C1 Full Shuto Expressway` 0→4→2→0.
