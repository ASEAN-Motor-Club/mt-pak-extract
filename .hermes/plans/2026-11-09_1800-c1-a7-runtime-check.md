# C1 A7 — runtime acceptance via UE4SS, not driving

Date: 2026-11-09. Replaces "freeman drives around and reports" with a collector that reads the
running game's own state. One launch, one JSON, then analysis happens off-machine where it can be
re-run freely.

## Why this exists

A7 as written asks a human to judge six things in a car. Four of them are actually engine facts, not
perceptual judgements, and the engine will state them if asked:

| A7 item | question in engine terms |
|---|---|
| paint/signs/foliage draw | does each actor's mesh resolve, is the component visible, and does every slot bind a real material (not WorldGridMaterial)? |
| sit at the same height | what Z does the renderer place the mesh at, and where does a downward trace hit relative to the road under it? |
| no resistance | does a downward trace over the no-collision actors hit anything, and what does it hit? |
| kerb still stops | same trace over structural actor bounds — must hit |
| nothing missing | actor counts per layer vs the built set (554 structural / 238 NC) |
| z-fighting | NOT answerable this way — needs rendered pixels; remains a visual check |

So the collector answers five of six, leaves z-fighting (and UV/winding sanity) as the only genuinely
visual residue.

## Design

`Mods/C1A7Check/Scripts/main.lua` — a collector, not a judge:

- walks `FindAllOf("StaticMeshActor")`, keeps actors whose mesh path is under `/Mods/C1Full/`
- per actor: name, layer (structural / nc), mesh path, location, `bVisible`, `Mobility`,
  `CollisionProfileName`, slot count
- per slot (`mesh:GetMaterial(i)` — never the `StaticMaterials` struct array, which is the documented
  Lua-GC hazard on this build): the material object the renderer will bind, plus its `BaseColor`
  texture, so a missing texture surfaces as a path that does not exist rather than a silent fallback
- traces: 3x3 grid inside each NC actor's bounds, 40 cm above its top, 6 m down, recording what the
  hit actor is. `none` = free space, `nc` = our own no-collision mesh (bad), `other` = structural
- detail cap: all 238 NC actors get full slot detail; structural actors get it for the first 260 and
  a count beyond that, to keep the file analysable

Writes `D:/c1_a7check.json`, plus `D:/c1_a7check_alive.txt` as load proof. Auto-collects once the map
is loaded and >=700 of our actors exist; F10 re-collects on demand.

**API risk is handled by design**: every call is pcall'd with a named failure, and the trace helper
tries two signatures and records which one worked in the JSON (`trace_api`). A failed API produces a
diagnosis, not a crash — that is what makes one launch per iteration achievable.

## Verdict rules (applied off-machine)

- `counts.structural != 554` or `counts.nc != 238` -> layer missing, stop
- any actor with `mesh` path that does not exist in the installed paks -> invisible geometry
- any slot whose `mat` contains `WorldGridMaterial` -> material binding lost at runtime
- any slot whose `bc` is `NULL`/`NO_FN` or a path not in the pak -> texture does not resolve
- any NC actor with `profile` other than `NoCollision`, or `mobility` not `Static` -> will interact
- any NC actor with `trace_summary.nc > 0` -> its own geometry blocks (the c0_-21 class of bug)
- any structural actor with `trace_summary.none` == 9 -> nothing to collide with, kerb/anchor missing

## Install

1. `Mods/C1A7Check/Scripts/main.lua`, `Mods/C1A7Check/enabled.txt`
2. append `C1A7Check : 1` to `Mods/mods.txt` (backup first)
3. launch the game, load into C1Full; the file appears within ~15 s of the map loading

## Reporting

Collector JSON is pulled to the agent host and judged against `pakset_v9` manifests + `slotmap.json`.
The judgement is a script, so re-running it after any fix costs nothing and needs no second launch.
