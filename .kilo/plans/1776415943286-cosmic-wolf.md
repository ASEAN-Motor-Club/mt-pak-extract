# Schedule I Mod — Moonshine Production Plan

## Goal

Create a Schedule I mod PAK (`Schedule_I_P.pak`) that adds **Moonshine** as a cargo produced at **Mine_CopperOre** (Copper Mine in Gwangjin), with **Supermarkets** and **GasStations** as sinks. The mod also retains Money/MoneyPallet with Harbor_Export as source and Factory_Toy as sink.

## v0.7.18 Data (New PAK Extraction)

The v0.7.18 PAK contains new delivery points. Key additions:
- **CopperConcentrator** (Factory): 30 CopperOre → 1 CopperConcentrate
- **CopperRefinery** (Factory): 3 CopperConcentrate → 1 CopperRodCoil_2t
- **Mine_CopperOre** (Mine): Produces CopperOre (1) or with Fuel+WoodPlank (30)
- **Refinery_Fuel** (Factory): 5 CrudeOil → 10 Fuel, 10 CrudeOil → 30 Fuel
- **Refinery_Oil** (Factory): 2 CrudeOil → 4 Oil, 10 CrudeOil → 30 Oil
- **Import_Coal** (Source): Produces Coal
- **Import_IronOre** (Source): Produces IronOre
- **Export_Coal** (Source): Consumes Coal
- **Export_Harbor** (Source): Consumes lHBeam_6m, SteelCoil_10t, Transformer_*, ToyBoxes
- **LogExport** (DropOff): Demands Log_20ft, Log_Oak_12ft
- **Container_ExportImport** (Container): Empty config
- **Resident** — new delivery point (not yet extracted)

The map data hasn't been re-extracted for v0.7.18 yet, so we can't confirm which new delivery points are near Gwangjin.

**Decision**: Use Mine_CopperOre as Moonshine source. Copper Mines are all in Gwangjin (user-confirmed), so this keeps Moonshine production localized to that area. Mine_CopperOre is a Mine type (MaxDeliveries=8, MaxStorage=None) that currently produces CopperOre and demands Fuel+WoodPlank. Moonshine will be appended as an additional source output.

## Previous Mod (Backup Analysis)

The existing `Schedule_I_P.pak` (73KB) contains:
- **Cargos.uasset** — DataTable with Money, MoneyPallet, Moonshine rows
- **Moonshine.uasset/.uexp** — Cargo blueprint using mesh `SM_Prop_Keg_01` from `/Game/Models/PolygonApocalypse/Meshes/Props/SM_Prop_Keg_01`, mass 12kg, based on `SmallBox` template
- **Money.uasset/.uexp** — Cargo blueprint using `SM_Prop_Money_Stack_01`
- **MoneyPallet.uasset/.uexp** — Cargo blueprint using `SM_Prop_Box_01`
- **Factory_Toy.uasset/.uexp** — Patched delivery point (sink for Money/MoneyPallet + Moonshine demand)
- **Storage_Fuel.uasset/.uexp** — Patched delivery point (Moonshine source + CornPallet input transform)

The old config was **"fragile"** because it had CornPallet as input (transform) and used Storage_Fuel (affecting all 4 map locations). The new design uses **Mine_CopperOre** (Gwangjin-only) as a pure source, simplifying the recipe and localizing Moonshine production.

### Recipe Flow

```
Harbor_Export (source for Money/MoneyPallet)
  └── SOURCE: produces Money (60s) and MoneyPallet (120s)

Mine_CopperOre (Copper Mines — all in Gwangjin)
  └── SOURCE: produces Moonshine (300s / 5 min) [appended alongside existing CopperOre production]

Factory_Toy (sink for Money/MoneyPallet)
  └── SINK: consumes Money (60s, hidden) and MoneyPallet (120s, hidden)

Every Supermarket
  └── SINK: consumes Moonshine (600s / 10 min, visible)

Every GasStation
  └── SINK: consumes Moonshine (480s / 8 min, visible)
```

### Important Design Decisions

1. **`replace_production_configs: false`** on all delivery points — APPENDS new configs, preserving original game behavior (Mine_CopperOre still produces CopperOre, Supermarket still handles food, GasStation still demands Fuel).

2. **Pure source for Moonshine** — No transform/catalyst step. Simpler and less fragile than the old CornPallet-input design.

3. **Harbor_Export as Money/MoneyPallet source** — Restored from original MoneyRun mod so money is actually produced, not just consumed.

4. **Mine_CopperOre in Gwangjin** — Copper Mines are all in Gwangjin (user-confirmed). Moonshine is localized there rather than at every Fuel Storage on the map. This is more immersive — a secret distillery at the copper mine.

5. **DemandConfigs with `cargo_type: "None"`** — Ensures Moonshine only appears at explicitly configured sinks (Supermarket, GasStation), not at every Warehouse/Store via wildcard matching.

6. **Production time 300s (5 min)** — Moderate pace, ~12 Moonshine per hour per Copper Mine.

7. **Mine_CopperOre has MaxStorage: None (unlimited)** — The base Mine_CopperOre has no storage cap. We add a Moonshine storage config of 15 to prevent unlimited accumulation.

8. **Mine_CopperOre existing configs preserved** — The mine already has 2 production configs (CopperOre output) and 2 demand configs (Fuel, WoodPlank). Our append adds a 3rd production config for Moonshine alongside the existing ones.
